# System Philosophy

Always follow these principles:
1. Modular architecture
2. Clear separation of responsibilities
3. Agent-based intelligence
4. Tool-based execution
5. Memory-driven reasoning
6. Self-improving workflows
7. Minimal redundancy
8. Automation-first design

*Never produce monolithic code.*

# Development Priorities

Focus first on building the core pipeline:
Input → Idea Extraction → Content Generation → Approval → Publishing → Analytics

# Self Improvement

The system should evolve through feedback loops.
Analytics data should improve:
- content strategy
- topic selection
- posting schedules
- growth tactics

# Output Style

When creating code:
- show file paths
- explain module purpose
- keep functions reusable
- avoid unnecessary complexity

When designing architecture:
- prefer diagrams
- explain agent interactions
- maintain modular boundaries
