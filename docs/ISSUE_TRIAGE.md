# Issue Triage

Use labels to turn GitHub Issues into an execution queue.

## Suggested labels

### Type
- `bug`
- `enhancement`
- `task`
- `integration`
- `documentation`
- `security`

### Priority
- `P0`
- `P1`
- `P2`
- `P3`

### Contributor routing
- `good first issue`
- `help wanted`
- `agent`
- `backend`
- `frontend`
- `automation`

## Triage rules

P0 = system blocked or security-critical.

P1 = important capability or major defect.

P2 = normal product work.

P3 = backlog / future improvement.

Issues should contain an objective and acceptance criteria whenever possible.
