# JAN AI — Front-End Application Code Blueprint (Vite + React + Tailwind) This document provides the functional structure to transform the JAN AI high-fidelity designs into a clickable, demo-ready SaaS application. ## 1. Project Setup & Configuration ```bash # Initialize Vite with React and TypeScript npm create vite@latest jan-ai -- --template react-ts cd jan-ai # Install core dependencies npm install lucide-react react-router-dom axios clsx tailwind-merge framer-motion zustand # Setup Tailwind CSS npm install -D tailwindcss postcss autoprefixer npx tailwindcss init -p ``` ## 2. Directory Structure (Application Scale) ```text src/ ├── api/ # API client (Axios) and endpoint definitions ├── components/ # Shared components (Layout, Nav, Forms, Cards) │ ├── layout/ # AppShell, TopNav, SideNav │ ├── ui/ # Buttons, Inputs, Modals, Progress Indicators │ └── content/ # Studio-specific components (ScoreCard, LogicNode) ├── context/ # Auth, Workspace, and System Health context ├── hooks/ # Custom hooks (usePipeline, useAccount) ├── pages/ # Screen implementations │ ├── auth/ # Sign-up, Onboarding, Profile Setup │ ├── dashboard/ # Multi-account Dashboard │ ├── studio/ # Content Studio, Strategy Forge, Pipeline OS │ └── settings/ # System Config, Logs, FAQ ├── store/ # Zustand stores for global UI state ├── types/ # Global TypeScript interfaces └── App.tsx # Main Router & Provider wrapper ``` ## 3.
