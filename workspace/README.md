# Workspace Placement

This kit is designed to be copied into the cloned repository.

Recommended location on your laptop:

`<your-workspace>/Startup-borardcasting-system/`

Keep the GitHub repository as the canonical source. If you later create a larger Jan AI / Startup Bot monorepo, move the application into a dedicated package such as:

`apps/startup-broadcasting-system/`

Do not mix this repository's `.git` directory with another repository.
